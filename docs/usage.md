# 使用说明

## 日常使用

在首页、搜索页、普通视频推荐区等区域，插件会隐藏匹配的卡片，右下角显示当前过滤数量。关键词和时长阈值在详细设置中填写。

打开普通视频页 `/video/BV…` 或 `/video/av…`，页面右下角提供“预览字幕”“复制字幕”“下载字幕”。工具栏弹窗也提供复制与下载。多 P 视频按当前 URL 的 `p` 参数提取当前 P，切换视频 / 分 P 时会清除旧预览。字幕在当前标签页内缓存，预览后再复制、下载不需重复提取；插件重载或更改字幕获取相关设置后重新提取。

预览只读取字幕，不自动下载或复制；B 站字幕的时间是可点击按钮，点击后跳到对应时间，保持当前播放 / 暂停状态。“复制字幕”复制无时间戳的正文，适合粘贴到笔记；“下载字幕”使用设置中的 SRT / VTT / TXT 格式。

下载目录在详细设置里填写，例如 `Bilibili/字幕` 会保存到 `Downloads/Bilibili/字幕/`。留空使用 Firefox 默认下载目录，若 Firefox 已配置其他默认目录则以浏览器配置为准。WebExtension 的下载接口无法直接保存到任意绝对路径；需要其他磁盘、目录时启用“每次下载时选择保存位置”，由原生保存对话框选择。识别可以持续较长时间，关闭弹窗不会中断后台任务。

详细设置底部展示最近过滤的视频，可点击标题查看被过滤视频，点击“清空过滤历史”删除已有记录。关闭过滤规则不会删除历史，反复扫描同一卡片不会重复写入。

若选择“中文”官方字幕但只有英文轨，不会静默下载英文轨：启用内置识别回退时按“音频识别语言”生成原语言字幕。这两个语言选项独立，生成中文**翻译**字幕并非本插件功能。

## 范围与限制

- 广告识别依赖明确的 DOM 推广标记或广告链接，不读取视频画面，不能识别 UP 主视频里的口播广告或无标记推广。
- 使用页面显示的卡片标题与时长，不额外批量请求卡片详情。站点 DOM 改版或新卡片布局可能需要更新 `extension/content.js` 的选择器。
- 字幕烧录在画面中但没有独立字幕轨时，从音频识别回退，**没有实现 OCR**。如果视频的字幕轨未由 B 站接口公开，也无法直接读取它。
- 仅支持普通视频页，暂不支持直播、番剧 / 影视页面和一次下载所有分 P。
- 使用当前 Firefox 的 B 站登录状态访问官方接口；后端不接收 Cookie。视频权限、会员限制及风控仍可能使接口失败，不绕过访问限制。
- 音轨只允许 HTTPS 的 `bilivideo.com` / `bilivideo.cn` CDN。新 CDN 域名需要显式适配；DASH 音轨优先，只有单文件时才使用普通播放文件，不支持多段 FLV 合并。
- 每个视频标签页只启动一个任务；内置服务串行识别，最多 3 个运行 / 排队任务。上限为 3 小时、音轨文件 256 MiB；音轨全量下载和解码，内存开销随长度增长。
- 关闭视频标签页会取消其排队或运行中的识别，Firefox 退出或插件重载会中断任务。切换视频或分 P 后旧结果不会显示在新视频预览中；旧任务结束前不能启动同标签页的新任务。

## 本地数据

设置、令牌和过滤历史存在 Firefox 扩展本机存储中；过滤历史不上传、不同步，最多保留 100 条。剪贴板仅在点击复制时写入，不读取已有剪贴板内容。偏好标题、标注和训练权重仅发到本机服务，不上传云端；自动反馈通过 B 站自身界面提交。字幕模型文件保存在浏览器 Cache Storage，音频仅在插件内处理，不上传识别服务。偏好模型、标注和服务令牌存在 `backend/.runtime/`，已通过 `.gitignore` 排除。打包脚本仅收集 `extension/`，不会把这些目录放进 XPI。音轨请求包含 B 站播放接口提供的临时签名 URL，不会把这些 URL 写进正常访问日志。模型下载和访问 B 站仍是正常联网请求；项目不包含第三方统计或云端识别上传。
