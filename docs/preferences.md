# 实验性视频偏好

偏好模型完全在 Firefox 插件内运行，不需要安装 Python 或启动服务。

## 使用

1. 在工具栏弹窗或详细设置开启“视频偏好总开关”。开关持久保存，打开后可持续标注，刷新页面也保留标注入口。
2. 在视频标题旁的三点菜单选择“很喜欢 / 喜欢 / 不喜欢 / 很不喜欢”。重复标注更新原来的评级，不增加视频数量。仅标注不启动模型。
3. 至少标注 **31** 个不同视频后，在详细设置点击“训练模型”。训练独立于页面筛选执行，首次下载并缓存 MiniLM，训练个人 Transformer + MLP。训练日志实时显示下载、标题编码、各轮损失、完成或错误；保留当前后台会话最近一次训练的最多 300 条记录，重开设置页仍可查看，浏览器或插件重启后清除。
4. 在工具栏开启“在这个页面开启筛选”，只加载已保存的训练模型并推理，不触发训练。未训练或加载失败时保留视频；标注有更新时仍可使用已有模型。
5. 隐藏阈值默认为 **0.35**，严格低于阈值时隐藏。关闭筛选恢复模型隐藏的视频并保留标注入口；关闭总开关同时关闭所有页面的偏好筛选。基础广告、关键词和时长规则仍各自运行。
6. 新增、修改或导入标注只保存数据；需再次点击“训练模型”更新。训练采用点击时的标注快照，期间新增标注留待下一次手动训练。训练期间暂缓偏好筛选，完成后已开启页面自动使用新模型。关闭筛选或设置页不中断训练；清空模型会取消训练并关闭页面筛选。
7. 每次打开、刷新或重新打开网站后需手动开启筛选；网站内单页导航保留当前文档会话。弹窗和页面浮窗的“已过滤 … 个视频”旁可展开当前页面实际隐藏的视频，查看标题、原因并打开视频。

自动“不感兴趣”默认关闭。明确开启后，分数严格低于反馈阈值（默认 **0.08**，不高于隐藏阈值）才尝试点击 B 站原生菜单。只在前台标签页执行，全局每 10 秒最多一次、同一视频每天最多一次；找不到入口或需要额外确认时跳过。这会影响 B 站后续推荐，是否成功以站点为准。

关键词过滤另有独立的“命中关键词的视频自动点击‘不感兴趣’”开关，不需要开启视频偏好或训练模型。命中关键词并被隐藏的卡片使用相同的原生菜单匹配、前台限制和领取锁；两类自动反馈共用同一份去重记录，同一视频每天只会尝试一次。

## 模型与训练

基础编码器为 [Xenova/paraphrase-multilingual-MiniLM-L12-v2](https://huggingface.co/Xenova/paraphrase-multilingual-MiniLM-L12-v2)，是原多语言 MiniLM-L12 的 ONNX 量化版本。基础参数冻结，在 CPU WASM 中编码，每个标题独立处理，最多 48 token，输出 384 维 token 特征。固定独立编码避免量化结果随同批次其他标题变化。

个人训练头保留原结构：384 → 64 投影、可训练 CLS 与位置参数、单层 64 维四头 Transformer（前置 LayerNorm、128 维 ReLU 前馈），再接 LayerNorm → 32 维 GELU → 单输出 MLP。训练使用 TensorFlow.js CPU 自动微分，45 epochs、32 条 mini-batch、AdamW（学习率 0.001、衰减 0.05）、0.15 dropout 和全局梯度范数裁剪 1.0。四级标签对应 0、1/3、2/3、1 的目标，使用 BCEWithLogits，推理 sigmoid 输出 0–1。

编码、训练与推理在专用 Worker 中串行执行；未在训练且没有任何开启筛选的页面时终止 Worker，释放模型。已完成权重保留，未完成训练不发布。再次开启后恢复已保存的训练头；基础编码器在需要评分时加载。基础模型文件首次下载约 113 MiB，分词器约 16 MiB，实际内存开销高于下载大小。常驻特征缓存最多 256 个标题，标注最多 2000 条。

“偏好模型下载源”可选 HF Mirror 或 Hugging Face。模型文件下载后缓存，可在完整缓存时离线运行。切换下载源在下次启动计算时生效，可能需要重新缓存基础模型。字幕识别与偏好模型使用各自的 Worker，同时运行会增加 CPU 和内存占用。

## 保存与旧数据导入

标注保存在扩展 `browser.storage.local` 的 `preferenceData`，已完成的个人训练头保存在 IndexedDB 数据库 `bili-preference`，公开基础模型缓存位于 Cache Storage。关闭浏览器后保留这些数据。移除插件、清除扩展数据或更换 Firefox 配置可能删除数据，建议通过“导出标注”备份。

旧 Python 版本的 `backend/.runtime/preferences/labels.json` 可以直接通过“导入标注”导入。导入按视频 ID 合并，文件中的评级覆盖同 ID 的已有评级；点击“训练模型”后在插件内重新训练。旧 `head.pt` 不作为浏览器权重加载。导入失败不会更改已有标注。清空标注与模型会删除个人训练头，保留公开基础模型缓存。

## 验证与限制

自动测试覆盖与原 PyTorch 结构对应的前向输出、损失和各参数梯度抽样、padding 掩码、真实反向传播、损失下降、权重重载、张量释放、31 条门槛、训练版本更新和会话取消。真实 Firefox 检查使用公开 MiniLM ONNX 权重，在 31 条合成标题上运行 45 轮训练，验证评分、IndexedDB 保存、新 Worker 恢复和浏览器重启后的数据恢复。

分数仅依据标题，不是校准后的概率；31 条是启动门槛，不保证准确率。基础量化、初始化和随机训练过程可能使结果与旧 Python 版本不同。模型失败、下载失败或尚未就绪时保留视频。真实 B 站页面布局仍可能需要适配。

[原 Python 版本的 150 标题历史报告](../reports/preference-benchmark/REPORT.md)保留用于参考，不能代表当前浏览器量化版本的准确率。
