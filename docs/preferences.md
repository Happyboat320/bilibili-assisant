# 实验性偏好筛选

## 实验性视频偏好模型

偏好模型使用外置 Python 服务，依赖与启动步骤见[安装指南](installation.md#外置偏好服务)。字幕识别在插件内运行，两者独立。

1. 在详细设置中填写偏好服务令牌并确认连通。
2. 在插件工具栏弹窗中手动开启“本页启用偏好筛选”。每次重新打开网站、刷新页面、关闭再开标签页或重启浏览器后都要重新开启；B 站页面内的单页导航不重置当前文档会话。开启状态只存在后台内存，不写入设置，不自动恢复。此功能与“本地语音识别回退”相互独立。
3. 浏览视频卡片，点击标题旁的三点菜单，选择“很喜欢 / 喜欢 / 不喜欢 / 很不喜欢”。能识别原生菜单时追加选项，不替换原有项目；没有可识别的三点入口时，插件补充一个同样的 `⋮` 按钮。
4. 前 30 个不同视频只存标注，不加载基础嵌入、不训练或筛选。第 **31** 个标注后开始下载模型 / 训练，模型就绪后分批处理页面上所有可读标题，每批最多 20 个。重复标注同一视频更新标签，不增加样本数；没有视频链接时按规范化标题识别样本。
5. 隐藏阈值默认 **0.35**，仅严格低于阈值时隐藏。关闭功能恢复因模型隐藏的视频；基础过滤规则仍按各自设置运行。修改标签后旧评分失效，完成新版本训练后重新评分。
6. 自动“不感兴趣”默认关闭。单独开启时，分数严格低于反馈阈值（默认 **0.08**，且不高于隐藏阈值）的视频，会尝试点击页面明确存在的“不感兴趣”选项；全局最多每 10 秒一次，同一视频每天最多一次。只在前台标签页执行，找不到入口、需要进一步理由 / 确认或站点改版时跳过，不调用猜测的反馈 API。**该操作可能影响 B 站后续推荐，最终反馈是否成功以站点为准。**

**模型结构与资源取舍**：采用 [paraphrase-multilingual-MiniLM-L12-v2](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2)，它支持中文、英文等语言，384 维 token 嵌入，适合 CPU 上批量处理短标题。基础模型约 1 亿级参数，权重约数百 MB；它是相对大型语言模型的小型编码器，仍需要一定内存和首次下载时间。基础参数冻结，只训练 token 投影 → 单层 64 维、4 头 Transformer → MLP。新增层读取 token 序列，学习标题中的词语组合。

四级标签对应 0、1/3、2/3、1 的训练目标，输出范围 0–1。这只是个人偏好估计，不是校准后的“喜欢概率”；31 个样本只满足启动门槛，并不保证泛化准确度。建议同时标注不同主题的正面和负面例子，初期使用较低隐藏阈值。仅处理标题，不读取画面、封面、视频音频或完整内容来推断偏好。

数据与模型保存在 `backend/.runtime/preferences/`：`labels.json` 为去重标注，`head.pt` 为个人训练头，`embedding/` 为基础模型缓存。最多保留最近 **2000** 个不同视频的标注，常驻 token 特征缓存为最近 256 个标题。全部使用 CPU，限制到最多 4 个 CPU 线程，训练与推理任务串行。关机 / 服务重启后磁盘数据保留；再次手动开启页面时，首次请求加载与标注 revision 对应的已保存训练头，不重新训练同一版本。关闭页面不会清除标注或 checkpoint；请勿删除 `backend/.runtime/preferences/`。基础模型下载完成后可离线使用。设置页可查看计数 / 训练状态，并清空标注和训练头，保留基础模型权重。

服务断开、依赖缺失、模型未就绪或输出无效时，偏好筛选暂停，视频保留；其他过滤规则照常生效。开启偏好功能不会启动语音识别，关闭偏好后不再发起编码 / 推理请求；没有任何启用的页面时通知服务暂停。会话每 10 秒续约，浏览器退出或服务失联时最多 45 秒后在下一计算批次暂停。已进入模型加载 / 单个编码批次的操作不能瞬时取消，训练在 mini-batch 之间检查限制；未完成的新训练不会覆盖原有 checkpoint。暂未完成真实 B 站布局的端到端实测，菜单兼容性仍可能需要根据站点实际 DOM 调整。

### 150 个模拟标题的学习曲线

数据集：[150 条合成标题](../tests/fixtures/preference_titles.json)，访谈、硬核、户外、标题党、数码汽车、网络热梗各 25 条；每类前 20 条用于训练，后 5 条固定测试，合计 **120 训练 + 30 测试**，没有重叠。喜欢前三类，不喜欢后三类，并保留四级喜好标签。训练前缀按主题交错，确保小样本前缀接近均衡。

[完整实测报告](../reports/preference-benchmark/REPORT.md) · [逐条预测](../reports/preference-benchmark/predictions.json) · [CSV 学习曲线](../reports/preference-benchmark/learning_curve.csv) · [JSON 结果](../reports/preference-benchmark/results.json)

使用真实多语言 MiniLM token 嵌入和 CPU Transformer + MLP，规模 **20、30、40……120**，每个规模从头训练 45 epochs，种子 42/43/44 共三次；固定二分类阈值 0.5 和隐藏阈值 0.35，不用测试标签调整阈值。20/30 条的训练只用于独立离线诊断，**产品在 <=30 条时仍完全不运行偏好模型**。实验不写入个人标签 / 训练权重，使用独立 `backend/models/benchmark-preference/` 缓存，不改变浏览器开关。

在项目目录复现（需可选依赖）：

```bash
python3 scripts/generate_preference_dataset.py
backend/.venv/bin/python scripts/benchmark_preferences.py
```

若已安装 `.test-venv` 的可选依赖，也可用 `.test-venv/bin/python`。首次模型下载需联网；可设置 `HF_ENDPOINT=https://hf-mirror.com` 使用镜像下载公开模型文件。已有本地缓存时可加 `HF_HUB_OFFLINE=1` 离线运行。报告保存模型名称、Python/PyTorch 版本、训练耗时、分数及随机种子。

**解释限制**：这是一套人工合成、主题较明显的中文标题，只含 30 条固定测试，不能证明真实用户准确率。三个随机种子展示的是训练随机性而非泛化置信区间，样本更多时结果也未必单调上升。报告同时列出在 0.35 隐藏阈值下的误隐藏数与漏过滤情况，便于判断偏好筛选的实际影响。
